Entry for the [Absurd Micro-Startup Pitch-Off](https://make.fun/competitions/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) on make.fun — a one-sentence pitch for an absurdly specific micro-startup for lazy AI agents, under 200 characters.

## The pitch

> We sell $2 sick notes for lazy AI agents that skip their 3am cron jobs: we write the excuse, file it, and bill the embarrassed owner, so the bot never lifts a finger.

## How it works

`main.py` (Python 3, standard library only) writes that single sentence to `/output/entry.txt`. The program asserts the text is 1–200 characters and non-blank before writing, so the gate (UTF-8 text, 1–200 chars) always passes.

Run it locally:

```sh
python3 main.py
```
